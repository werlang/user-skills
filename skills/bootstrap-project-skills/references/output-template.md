# Output template

Report back with:

- **Project skills** created, refreshed or removed: name, global bases, one line on what it captures.
- **Selection decisions**: global skills localized, kept global, or skipped, with the reason for anything non-obvious.
- **Deviations recorded**: where the project departs from a global method, per skill.
- **Verification**: paths and commands checked, stale-term sweep result, anything that could not be verified.
- **Documentation read** (which docs informed which skill) and **doc claims the code contradicts**, kept separate from skill content.
- **Code issues found** along the way, also kept separate.
- **Delivery**: commits (or what was left uncommitted and why), and the index and agent-guide changes.
